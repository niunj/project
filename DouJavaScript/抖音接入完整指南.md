## 1. 注册抖音开放平台账号

### 步骤 1.1：访问抖音开放平台

打开浏览器，访问：
```
https://developer.open-douyin.com/
```

### 步骤 1.2：注册账号

1. 点击右上角「注册」按钮
2. 选择注册方式：
   - 手机号注册（推荐）
   - 邮箱注册

3. 填写信息：
   - 手机号/邮箱
   - 验证码
   - 设置密码

4. 完成注册

### 步骤 1.3：实名认证（必须）

**个人开发者**：
1. 进入「账号设置」→「开发者信息」
2. 填写真实姓名、身份证号
3. 上传身份证正反面照片
4. 等待审核（通常1-3个工作日）

**企业开发者**：
1. 进入「账号设置」→「开发者信息」
2. 选择「企业认证」
3. 填写企业信息：
   - 企业名称
   - 统一社会信用代码
   - 企业法人信息
4. 上传营业执照
5. 等待审核（通常3-5个工作日）

**注意**：
- 个人开发者：最多创建 25 个小游戏
- 企业开发者：最多创建 50 个小游戏
- 内购功能需要企业认证

## 2. 创建小游戏应用

### 步骤 2.1：进入管理后台

登录后，点击右上角「控制台」或访问：
```
https://developer.open-douyin.com/console
```

### 步骤 2.2：创建小游戏

1. 点击「创建应用」或「小游戏」→「创建小游戏」

2. 选择小游戏类型：
   - **普通小游戏**：基于 JavaScript/Canvas 开发（推荐）
   - **Unity 小游戏**：基于 Unity 开发

3. 填写基本信息：
   ```
   小游戏名称：你的游戏名称
   小游戏简介：简短描述（20-200字）
   小游戏图标：上传 512x512 PNG 图片
   ```

4. 选择类目：
   - 休闲益智
   - 动作射击
   - 角色扮演
   - 策略经营
   - 体育竞速
   - 其他

5. 点击「提交」

### 步骤 2.3：等待审核

- 审核时间：通常 1-3 个工作日
- 审核通过后会收到通知
- 可以在「应用列表」查看状态

## 3. 获取必要信息

### 步骤 3.1：获取 AppID

审核通过后：

1. 进入「控制台」→「应用列表」
2. 点击你的小游戏
3. 在「基础设置」中找到：
   ```
   AppID: tt1234567890abcdef
   ```

**重要**：记录这个 AppID，后面配置需要用到。

### 步骤 3.2：获取 AppSecret（可选）

如果需要服务端 API 调用：

1. 在「基础设置」中找到「AppSecret」
2. 点击「生成」或「查看」
3. 验证身份后显示 AppSecret

**注意**：AppSecret 非常重要，不要泄露！

### 步骤 3.3：配置服务器域名（可选）

如果游戏需要网络请求：

1. 进入「开发设置」→「服务器域名」
2. 配置：
   ```
   request 合法域名：https://api.yourdomain.com
   uploadFile 合法域名：https://upload.yourdomain.com
   downloadFile 合法域名：https://download.yourdomain.com
   ```

## 4. 配置项目

### 步骤 4.1：修改 project.config.json

打开你的项目文件：
```
/home/mte/FOLD/DouJavaScript/universal-game/project.config.json
```

修改以下字段：
```json
{
  "appid": "tt1234567890abcdef",  // 替换为你的 AppID
  "projectname": "your-game-name",
  "description": "你的游戏描述"
}
```

### 步骤 4.2：修改 game.json（可选）

```
/home/mte/FOLD/DouJavaScript/universal-game/game.json
```

根据需要调整：
```json
{
  "deviceOrientation": "portrait",  // portrait 竖屏 / landscape 横屏
  "showStatusBar": false,
  "networkTimeout": {
    "request": 10000,
    "connectSocket": 10000,
    "uploadFile": 10000,
    "downloadFile": 10000
  }
}
```

### 步骤 4.3：合并代码文件

将以下文件合并成一个 `game.js` 文件：

```bash
# 在 universal-game 目录下
cd /home/mte/FOLD/DouJavaScript/universal-game

# 创建合并后的文件
cat src/adapter.js src/ad-manager.js src/game-core.js game-douyin.js > game.js
```

或者手动复制粘贴：
1. 打开 `src/adapter.js`，复制全部内容
2. 打开 `src/ad-manager.js`，追加到 game.js
3. 打开 `src/game-core.js`，追加到 game.js
4. 打开 `game-douyin.js`，追加到 game.js
5. 保存为 `game.js`

## 5. 安装抖音开发者工具

### 步骤 5.1：下载开发者工具

访问下载页面：
```
https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/developer-instrument/developer-instrument-update-and-download
```

选择对应版本：
- **Windows**：下载 .exe 安装包
- **Mac (Intel)**：下载 x64.dmg
- **Mac (Apple Silicon)**：下载 arm64.dmg

**Linux 用户**：
- 参考 [Linux开发环境配置.md](../Linux开发环境配置.md)
- 推荐使用虚拟机或 Wine

### 步骤 5.2：安装

**Windows**：
1. 双击下载的 .exe 文件
2. 选择安装路径
3. 点击「安装」
4. 完成后启动

**Mac**：
1. 双击下载的 .dmg 文件
2. 将「抖音开发者工具」拖到「应用程序」
3. 打开「应用程序」→「抖音开发者工具」

### 步骤 5.3：登录

1. 启动抖音开发者工具
2. 扫码登录（使用抖音 App 扫码）
3. 登录成功后进入主界面

## 6. 导入项目

### 步骤 6.1：导入项目

1. 在抖音开发者工具中，点击「导入项目」或「+」

2. 选择项目目录：
   ```
   /home/mte/FOLD/DouJavaScript/universal-game
   ```

3. 填写项目信息：
   ```
   目录：选择项目文件夹
   AppID：输入你的 AppID（或选择已有应用）

   ```

### 步骤 6.2：项目结构检查

导入后，确认文件结构：
```
universal-game/
├── game.js              ✅ 主入口文件
├── game.json            ✅ 游戏配置
├── project.config.json  ✅ 项目配置
```

1. 导入成功后，模拟器会自动启动
2. 在模拟器中测试游戏：

   - 游戏逻辑是否正常
   - 分数、生命值显示
   - 游戏结束逻辑

3. 查看控制台：
   - 点击「调试器」标签
   - 查看 Console 日志
   - 检查是否有错误

## 7. 真机测试

### 步骤 7.1：准备测试手机

**Android 手机**：
1. 安装抖音 App（最新版本）
2. 手机开启开发者模式：
   - 设置 → 关于手机 → 连续点击「版本号」7次
   - 返回设置 → 开发者选项 → 开启「USB 调试」

3. 用 USB 连接电脑

**iOS 手机**：
1. 安装抖音 App（最新版本）
2. 需要配置开发者证书（较复杂）
3. 建议先使用 Android 测试

### 步骤 7.2：真机调试

在抖音开发者工具中：

1. 点击工具栏「真机调试」按钮

2. 选择设备：
   - Android：自动识别连接的设备
   - iOS：需要额外配置

3. 点击「调试」

4. 手机抖音 App 会自动打开游戏

5. 在开发者工具中：
   - 查看真机日志
   - 查看性能数据
   - 实时调试

### 步骤 7.3：预览测试

如果不需要调试，只想预览：

1. 点击工具栏「预览」按钮

2. 生成二维码

3. 用手机抖音扫码：
   - 打开抖音 App
   - 扫一扫 → 扫描二维码
   - 游戏自动打开

4. 在手机上测试游戏

### 步骤 7.4：测试要点

真机测试重点检查：

- [ ] 游戏加载速度
- [ ] 触摸响应是否灵敏
- [ ] 游戏流畅度（帧率）
- [ ] 不同机型适配
- [ ] 音效是否正常
- [ ] 分享功能
- [ ] 广告展示（如果已配置）
- [ ] 本地存储（最高分保存）
- [ ] 网络请求（如果有）

## 8. 上传发布

### 步骤 8.1：完善游戏信息

在抖音开放平台：

1. 进入「控制台」→「应用列表」→ 你的游戏

2. 完善基本信息：
   ```
   游戏名称：确认无误
   游戏简介：详细描述玩法
   游戏图标：512x512 PNG
   游戏截图：上传 3-5 张游戏截图
   游戏视频：上传游戏演示视频（可选）
   ```

3. 填写详细信息：
   ```
   游戏详情：详细介绍游戏玩法
   操作说明：如何操作游戏
   游戏特色：游戏亮点
   ```

4. 选择标签：
   - 选择合适的分类标签
   - 添加搜索关键词

### 步骤 8.2：版本管理

在抖音开发者工具中：

1. 点击工具栏「上传」按钮

2. 填写版本信息：
   ```
   版本号：1.0.0（遵循语义化版本）
   项目备注：本次更新内容
   ```

3. 点击「上传」

4. 等待上传完成（通常几秒到几分钟）

### 步骤 8.3：提交审核

上传成功后：

1. 回到抖音开放平台

2. 进入「版本管理」→「开发版本」

3. 找到刚上传的版本，点击「提交审核」

4. 填写审核信息：
   ```
   测试账号：提供测试账号（如果需要登录）
   补充说明：给审核人员的说明
   ```

5. 点击「提交」

6. 等待审核（通常 1-3 个工作日）

### 步骤 8.4：审核注意事项

审核可能被拒的原因：

- ❌ 游戏内容违规（暴力、色情等）
- ❌ 侵犯知识产权
- ❌ 游戏体验差（卡顿、闪退）
- ❌ 功能不完整
- ❌ 未接入防沉迷系统
- ❌ 隐私政策不合规

**审核通过后**：
- 会收到通知
- 可以在「版本管理」中看到「审核通过」状态

### 步骤 8.5：发布上线

审核通过后：

1. 进入「版本管理」→「审核版本」

2. 点击「发布」按钮

3. 选择发布方式：
   - **全量发布**：所有用户可见
   - **灰度发布**：先小范围测试（推荐）

4. 如果选择灰度发布：
   ```
   灰度比例：10%（逐步增加）
   灰度时间：1-7 天
   ```

5. 点击「确认发布」

6. 游戏正式上线！

### 步骤 8.6：发布后监控

上线后关注数据：

在「数据分析」中查看：
- DAU（日活跃用户）
- 新增用户数
- 留存率（次日、7日、30日）
- 人均游戏时长
- 付费率（如果有内购）
- 广告收入

## 9. 广告接入

### 步骤 9.1：申请广告权限

在抖音开放平台：

1. 进入「控制台」→ 你的游戏 →「流量主」

2. 申请开通广告权限：
   - 需要游戏已上线
   - 需要达到一定用户量（通常 DAU > 1000）
   - 等待审核

3. 审核通过后，可以创建广告位

### 步骤 9.2：创建广告位

1. 在「流量主」→「广告管理」中

2. 点击「创建广告位」

3. 选择广告类型：
   - **激励视频广告**：用户观看获得奖励
   - **插屏广告**：游戏结束时展示
   - **Banner 广告**：常驻展示（不推荐）

4. 填写广告位信息：
   ```
   广告位名称：复活广告 / 游戏结束广告
   广告位描述：详细描述
   ```

5. 提交创建

6. 获取广告位 ID：
   ```
   激励视频广告 ID：adunit-123456
   插屏广告 ID：adunit-789012
   ```

### 步骤 9.3：配置广告 ID

在项目中配置：

打开 `game-douyin.js`（或合并后的 `game.js`），找到：

```javascript
// 设置广告 ID（替换为你的真实广告 ID）
this.adManager.setAdIds({
  rewardedVideoId: 'adunit-123456',  // 替换为你的激励视频广告 ID
  interstitialId: 'adunit-789012'    // 替换为你的插屏广告 ID
});
```

替换为真实的广告位 ID。

### 步骤 9.4：测试广告

**开发环境测试**：

在抖音开发者工具中：
1. 模拟器会模拟广告展示
2. 查看控制台日志
3. 确认广告调用逻辑正确

**真机测试**：

1. 真机调试模式下
2. 触发广告展示：
   - 点击「观看广告复活」
   - 游戏结束时查看插屏广告

3. 确认：
   - 广告能正常展示
   - 观看完整广告后获得奖励
   - 广告关闭后游戏正常

**注意**：
- 测试广告可能展示测试素材
- 正式上线后会展示真实广告
- 确保广告不影响游戏体验

### 步骤 9.5：广告优化建议

**激励视频广告**：
- ✅ 游戏失败时提供复活机会
- ✅ 观看广告获得金币/道具
- ✅ 观看广告解锁关卡
- ❌ 不要强制观看
- ❌ 不要过于频繁

**插屏广告**：
- ✅ 游戏结束时展示
- ✅ 关卡切换时展示
- ❌ 不要在游戏进行中展示
- ❌ 不要连续展示

**最佳实践**：
```
激励视频：用户主动选择，给予奖励
插屏广告：自然时机，不打断游戏
```

## 10. 常见问题

### Q1: AppID 在哪里找？

A: 抖音开放平台 → 控制台 → 应用列表 → 你的游戏 → 基础设置

### Q2: 真机调试连接不上怎么办？

A:
1. 确认手机已开启 USB 调试
2. 确认抖音 App 是最新版本
3. 尝试重新连接 USB
4. 重启开发者工具和手机

### Q3: 上传失败怎么办？

A:
1. 检查代码包大小（不能超过 4MB）
2. 检查文件路径是否正确
3. 查看错误日志
4. 尝试清理缓存后重新上传

### Q4: 审核被拒怎么办？

A:
1. 查看拒绝原因
2. 根据要求修改
3. 重新上传版本
4. 再次提交审核

### Q5: 广告收入如何查看？

A: 抖音开放平台 → 流量主 → 数据分析 → 收入数据

### Q6: 如何更新游戏？

A:
1. 修改代码
2. 在开发者工具中上传新版本
3. 提交审核
4. 审核通过后发布
