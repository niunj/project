## 七、盈利模式详解

### 7.1 广告变现（IAA - In-App Advertising）
**适合场景**：休闲游戏、益智游戏

**收入来源**：
- **激励视频广告**：用户观看广告获得奖励（复活、道具等）
  - eCPM：20-100元/千次展示
  - 用户接受度高，不影响体验

- **插屏广告**：游戏结束或关卡切换时展示
  - eCPM：10-50元/千次展示
  - 需注意展示频率，避免影响体验

**预估收益**：
```
假设：DAU = 10,000
激励视频广告展示率 = 30%（3000次/天）
插屏广告展示率 = 50%（5000次/天）
平均eCPM = 40元

日收入 = (3000 + 5000) × 40 / 1000 = 320元
月收入 ≈ 9,600元
```

### 7.2 内购变现（IAP - In-App Purchase）
**适合场景**：RPG、策略游戏、重度游戏

**收入来源**：
- 道具购买（皮肤、装备、道具）
- 关卡解锁
- 去广告
- 会员订阅

**注意事项**：
- 需要游戏版号
- iOS暂不支持内购（仅支持纯广告变现）
- 需要接入支付能力

### 7.3 混合变现（IAA + IAP）
**最佳实践**：
- 广告作为基础收入
- 内购作为增值收入
- 通过数据分析优化广告和内购的平衡点

### 7.4 平台激励
- **任务金激励**：鼓励内容经营
- **广告金激励**：放大推广收益
- **新游扶持**：上线15天免费流量

## 九、成功案例参考

### 9.1 休闲游戏案例
- **轻松拿捏了**：休闲益智类，通过激励广告变现
- **抓大鹅**：休闲动作类，社交裂变效果好
- **疯狂买买买**：休闲经营类，用户粘性高

### 9.2 成功要素
1. **玩法简单**：3分钟内能完成一局
2. **社交性强**：支持分享、排行榜
3. **变现合理**：广告展示不影响体验
4. **持续更新**：定期更新内容和活动

## 十、风险提示

### 10.1 政策风险
- 必须接入防沉迷系统
- 游戏内容需符合审核规范
- 内购游戏需要版号

### 10.2 技术风险
- 注意性能优化，避免卡顿
- 做好兼容性测试
- 预留无网/弱网兼容

### 10.3 运营风险
- 初期流量可能较少，需要耐心
- 关注用户反馈，及时优化
- 避免过度广告影响体验
