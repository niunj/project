# 快速接入指南

## 🚀 5分钟快速开始

### 第一步：注册抖音开放平台（2分钟）

1. 访问：https://developer.open-douyin.com/
2. 点击「注册」→ 手机号注册
3. 完成实名认证（个人或企业）

### 第二步：创建小游戏（3分钟）

1. 进入「控制台」→「创建小游戏」
2. 填写基本信息：
   ```
   名称：我的第一个小游戏
   类别：休闲益智
   图标：上传 512x512 图片
   ```
3. 提交并等待审核（1-3天）

### 第三步：获取 AppID（1分钟）

审核通过后：
1. 进入「控制台」→「应用列表」
2. 点击你的游戏
3. 复制 AppID：
   ```
   AppID: tt1234567890abcdef
   ```

### 第四步：配置项目（2分钟）

打开 `src/config.js`，修改：

```javascript
const CONFIG = {
  // 替换为你的 AppID
  appId: 'tt1234567890abcdef',

  // 广告 ID（稍后配置）
  rewardedVideoAdId: 'adunit-xxxxxxxx',
  interstitialAdId: 'adunit-xxxxxxxx'
};
```

### 第五步：合并代码（1分钟）

```bash
# 运行合并脚本
cd /home/mte/FOLD/DouJavaScript/universal-game
bash merge-code.sh

# 或手动合并
cat src/adapter.js src/ad-manager.js src/game-core.js game-douyin.js > game.js
```

### 第六步：导入抖音开发者工具（2分钟）

1. 下载并安装抖音开发者工具
2. 登录（抖音扫码）
3. 点击「导入项目」
4. 选择 `universal-game` 目录
5. 输入 AppID

### 第七步：测试（5分钟）

1. **模拟器测试**：在开发者工具中测试
2. **真机测试**：
   - 点击「预览」
   - 手机抖音扫码
   - 测试游戏

### 第八步：上传发布（3分钟）

1. 点击「上传」
2. 填写版本号：1.0.0
3. 回到开放平台 → 提交审核
4. 审核通过 → 发布上线

## 💰 广告接入（额外10分钟）

### 前提条件
- 游戏已上线
- DAU > 1000（建议）

### 步骤

1. **申请广告权限**
   ```
   开放平台 → 流量主 → 申请开通
   ```

2. **创建广告位**
   ```
   流量主 → 广告管理 → 创建广告位
   - 激励视频广告
   - 插屏广告
   ```

3. **获取广告 ID**
   ```
   激励视频：adunit-123456
   插屏广告：adunit-789012
   ```

4. **配置广告 ID**
   ```javascript
   // src/config.js
   rewardedVideoAdId: 'adunit-123456',
   interstitialAdId: 'adunit-789012'
   ```

5. **重新上传**
   ```
   合并代码 → 上传 → 提交审核 → 发布
   ```

## ⚠️ 常见问题

### Q: AppID 在哪里？
A: 控制台 → 应用列表 → 你的游戏 → 基础设置

### Q: 审核要多久？
A: 通常 1-3 个工作日

### Q: 代码包太大怎么办？
A:
- 移除未使用代码
- 压缩代码
- 使用分包加载

### Q: 如何测试广告？
A:
- 开发工具：模拟广告
- 真机：真实广告
