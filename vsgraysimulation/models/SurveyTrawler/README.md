# Survey Trawler

The demonstration uses the civilian `Trawler` asset from FlightGear fgdata, revision `e41d83b90f80b88b28a2027aa9caa6e02ae0d64a`. The unedited AC3D source and its wake texture are kept under `source` with the upstream GPL-2.0 license in this directory. [Upstream model](https://github.com/FGDATA/fgdata/blob/e41d83b90f80b88b28a2027aa9caa6e02ae0d64a/Models/Maritime/Civilian/Trawler.ac)

`Trawler.obj` keeps the source hull at metre scale. The survey conversion removes the static wake, trawl cables and buoys, and uses blue hull paint. It centres the hull horizontally, preserves the Y-up waterline, and maps the source bow from −X to +Z. The external transducer mount is a scene setting for the measurement demonstration.
