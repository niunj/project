# 海洋天气倒影与持久泡沫

本轮沿用单云对象、体素目标、连续波面、占用/断裂/刚体/碰撞/传感器链路。没有引入三维流体求解器，也没有降低水线积分和碰撞精度。

## 天空与云倒影

`rocky_env::WeatherReflection` 为每个地球视口维护 128×64 的上半球线性 HDR 辐射缓存。天空使用现有大气光学函数及同一透射 LUT，云直接复用 `planet_cloud_common.glsl` 的密度、散射和自阴影积分。缓存不是对屏幕截图作垂直翻转，因此也能采到相机视野以外的云。它仍是一个区域环境探针，忽略近云视差，不等于逐个水面位置的完整反射光线追踪，也不包含舰体/地形的几何倒影或天空穹顶的完整星图。

海面根据当前波浪法线反射方向查询缓存，五点滤波近似风浪粗糙度；曝光在最终水面着色时执行，避免日夜切换时复用旧曝光。缓存 alpha 保留云遮蔽，用于近似抑制日月高光；它不是覆盖整个海域的精确云影贴图。既有 Fresnel、太阳/月亮高光、吸收、入散射和海雾继续使用原链路。

天气不变时按仿真时间约 0.25 秒刷新一次；移动超过 12 米、太阳/月亮方向、云/风/雾等关键参数改变时刷新。暂停不会累计墙钟运动。记录实际发生过的预渲染命令后才提交缓存状态，避免把被节流的 UI 更新误当成已经生成倒影。纹理在同一 Vulkan 设备创建，离屏写入和海面读取之间有显式渲染通道依赖。预渲染顺序同时修正为先初始化/推进共享 GPU 云场，再进行倒影和时间重建，避免读取未初始化或上一阶段的云状态。

启用场景天气时，海面着色读取当前风速、风向和已积分的风程。风程用于平移表面细纹和风生泡沫，海面反光随风速逐渐变宽。白沫由已有的局部浪面坡度、随机分布和受限的风速经验关系共同控制，远距离用平均覆盖率过渡。场景天气关闭时读取海洋自身风速和风向。该光学细节与用于浮力、碰撞和传感器的连续波面分辨率独立，显式海况设置则更新各消费者共享的波浪参数。 [海面坡度与太阳闪光观测](https://opg.optica.org/josa/abstract.cfm?uri=josa-44-11-838) · [风速与白沫覆盖率研究](https://journals.ametsoc.org/abstract/journals/phoc/10/12/1520-0485_1980_010_2094_opldoo_2_0_co_2.xml)

## 船边浪花、持久泡沫与尾流

`VoxelOcean::foam` 是独立于短寿命扰动波包的光学沉积记录，最多 192 项。每项保存位置、长宽、方向、出生时间、寿命、强度和随机种子，随检查点保存、恢复。老场景缺少 `foam` 时仍可加载；新记录需要支持此字段的引擎版本。

- 固定仿真时间节拍从接水的运动物体两侧及船尾沉积；碎块扫掠入水事件也生成沉积。
- 沉积随既有海流和少量表面风漂移，宽度随年龄扩散、强度按面积及寿命衰减；过期和超容量记录被清理，不无限增长。
- GPU 将记录实例化光栅到相机附近 1024×1024 米、512×512 的泡沫覆盖缓存，每片沉积只处理自身覆盖的像素。场景时间/源状态和缓存区域不变时不重绘。
- 海面每像素只查询一次覆盖缓存，再叠加原有浪峰破碎、小尺度纹理和近船边细沫。船边即时白边改用圆滑轮廓，避免原来的矩形框。

这里使用物体边界近似水线形状，不是实测舰体流场；2 米缓存单元不表示物理体素变粗，小于缓存尺度的泡沫由既有近景光学细节补充。缓存边缘渐隐；缓存之外不显示这层持久泡沫，但记录仍存在，回到附近会重新生成。泡沫不增加液体质量、浮力、碰撞体或波面高度；本轮也没有将泡沫参数接入定量红外/雷达辐射模型。

## 验证与限制

使用台北新 GLO-30 DSM 和 2024-02-14 Sentinel-2B 影像，海岸地图及水位基准保持原配置。DSM 水面不是海床，没有新增实测水深、潮汐或近岸破浪数据。海岸体素表面的 `source_coarse=true` 原值被保留：该质量指标同时把源采样间距与最短显示网格边比较，并非表示回退到了旧全球粗数据。实际源间距仍为 30.92 米 / 10 米。

原始 Vulkan 实拍和报告在 `build/ocean-weather`。优化前二进制在修改生产渲染代码前保存。`weather-before-captures` 与 `after` 使用同一舰船、相机、UTC、固定物理步长和推进目标：

```sh
VSGRAYSIM_OCEAN_WEATHER_PASS=1 build/gui/sim_earth_gui_tests \
  --scene-ocean-capture build/ocean-weather/after
ctest --test-dir build -R 'voxel_ocean_consistency|voxel_ocean_gpu_parity|earth_cloud_ocean_consistency|voxel_earth_unified_scene|scene_package_authoring|cloud_temporal_reprojection_gpu' --output-on-failure -j1
```

验收独立记录冻结场景渲染、每次推进 100 ms 的浮力、全部仿真推进以及仿真加原生渲染耗时。原生渲染包含天气显示更新、提交和 `deviceWaitIdle`，不是 GPU 时间戳；截图编码、文件 IO、预热/导入和检查点不计入稳定帧耗时。完整周期不能由冻结渲染耗时替代。

GPU 回归实际执行生产泡沫光栅管线并读回覆盖图，检查有限值、随流漂移、年龄衰减和过期清空；水面高度、法线、光学界面及海雾继续与 CPU 对照。CPU 回归检查记录的严格加载、检查点往返、过期清理，以及泡沫不改变任何波面/速度采样。原有碎块入水和检查点重放测试继续执行。

当前军舰用假定均匀体密度标定，缺乏真实重心、稳心高度、舱室和推进数据。优化前 10 秒测试已出现明显侧倾；本轮保留原动力学并比较轨迹，不把这轮画面验收称为舰船稳性验收。浮力仍是完整仿真的主要成本。

主带云航段和初始机位保持同一云量。额外天气用例增加了运行时云量断言和纯海面像素差检查；旧基线程序的用例切换只改配置、没有更新运行中的云模块，实际云量一直为 0.65，因此其“晴空”和“高云量海雾”两项不作匹配的前后对比。日间带云、日落、夜间仍可按同云量对比。

具体前后中位数、P95、轨迹差及截图链接见同目录的比较报告。高分辨率和多显控的性能需要另测，不能从单视口结果外推。

最终 RTX 4060 Laptop、960×540 原生视口的实测如下。动态数据每条推进 100 ms（5 个 20 ms 固定步），共 100 条；冻结渲染单独取 30 帧。

| 范围 | 优化前中位数 | 本轮中位数 | 本轮 P95 |
|---|---:|---:|---:|
| 冻结场景渲染 | 11.88 ms | 11.76 ms | 12.21 ms |
| 动态原生渲染 | 40.69 ms | 54.26 ms | 117.68 ms |
| 浮力计算／推进 100 ms | 231.71 ms | 213.69 ms | 1542.24 ms |
| 完整仿真推进／100 ms | 297.40 ms | 273.15 ms | 1754.30 ms |
| 完整周期：推进＋原生渲染 | 351.37 ms | 346.24 ms | 1857.08 ms |

新增倒影/泡沫增加动态渲染成本；冻结时的缓存复用没有造成类似开销。浮力算法本轮未优化，其前后差异只能按运行波动解释，不能宣称算法提速。完整周期仍明显慢于实时；P95 又受到现有假定密度军舰侧倾后浸水积分复杂度影响。

100 个样本的位置和速度最大绝对差均为 0，整个检查点移除新增光学泡沫字段后完全相等。最终保存 75 项泡沫沉积。显示／刚体射线最大距离差为 0.0000161071 米。晴空／带云的海面区域 `[80,360]–[880,520]` 平均 RGB 绝对差为 1.4833 / 255，证明运行时云量改变确实影响海面；该指标不代表真实性评分。六项重建后的回归及云模块 smoke 均通过。
