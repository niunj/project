# 单云对象：散射、自阴影、雾与时间重投影

本页保留首轮散射/时间重建的实现与历史验收数据。后续 [云形态与日光层次改进](cloud_natural_shape.md) 已同步调整 CPU/GPU 凝结体形态；下面的“相对旧版本密度不变”结论仅适用于本页记录的当时版本，不能套用到形态改进后的程序。

本轮保留单云对象、随机种子、连续密度、生命周期、风运动和体素物理链路。改动是显示与光照层，没有将云换成立方体、贴图粒子或另一套物理状态。以 DCS 的体积天气技术方向为参照，不表示移植其实现或达到同等画质。

## 渲染实现

`planet_cloud_common.glsl` 供直接渲染与离屏渲染共同使用。单云分箱、空区跳跃、薄边细节与密度函数沿用原实现。

- 自阴影改为沿日光/月光方向的 6 段光学深度积分，天空方向另取 4 段；光线步距递增，覆盖自身和相邻云团。使用同一连续密度和既有消光函数。
- 光照使用三阶减缩散射闭合：高阶逐渐降低方向性及有效光学深度，得到较亮的受光边和更有厚度的背光面。这是有界近似，不是精确多次散射、实测云滴分布或辐射计标定。
- 清空气溶胶/大气沿用既有有限路径处理；新增雾与地形、远海共用指数高度衰减和能见度参数。云按平均可见距离处理雾的透射与入散射；空天空独立作曲率感知的路径积分，地形通过逆 Z 排除，海域通过椭球交点排除，避免对已处理水面再叠一层雾。
- 云光线也在地球椭球处截断，避免积分到地球背后的云。前景实体继续使用当前逆 Z 深度测试。

雾是可选的显示介质，不强制把高空地面覆盖成蓝白色。Earth 特性参数：

```json
{"cloud_objects":true,"fog_visibility_m":18000,"fog_height_m":220}
```

`fog_visibility_m=0` 关闭附加雾；高度单位为米。若场景含现有 `VoxelOcean`，优先沿用海洋的 `sea_fog` 参数及同一水位基准。该参数是附加雾层的消光标尺，基础大气仍单独计算，不能将其当作已标定的综合气象能见度。没有新增实测天气输入或降雨/冰相物理求解。

## 时间重投影

`CloudTemporal` 为每个地球视口独立维护显示历史：

1. 在窗口宽、高各一半的目标上积分云，输出曝光映射前的预乘线性辐射、透明度、平均距离与首个可见距离。
2. 在原窗口尺寸执行 compute 重建；按当前采样位置、上一帧相机矩阵和平均风位移反投影。
3. 检查投影范围、云的距离及透明度一致性，并用当前 3×3 邻域约束历史辐射与透明度。新变清的像素直接清除历史；合成深度始终采用当前帧结果。
4. 最后才做曝光映射与逆 Z 合成。历史中不包含地形、飞机、仪表或 UI，因此不会把它们拖进云层。

大时间跳变、倒带、明显机位切换、天气参数改变、云场重定位、窗口尺寸变化会使历史失效。曝光在最终合成时读取，不把旧曝光结果累加进历史。历史推进依据实际记录过的云渲染命令，不把 Qt 调用次数、被节流的帧或隐藏的云层当作已渲染历史。

历史仅用于显示，不回写云密度、物理、阴影或传感器。专题没有显式外部时钟时，云的年龄/风位移与天空一样跟随当前场景快照时间，暂停后不再按墙钟继续漂移。隐藏云时停止该离屏显示工作；显示恢复时重新建立历史。资源在重新分配成功后才替换旧资源；分配失败保留直接体积渲染，并在日志中说明，等待视口尺寸改变后重试。

默认半分辨率云采样＋原尺寸重建是实际性能收益的一部分，不应描述为全分辨率逐像素积分，也不是降低物理体素精度。`VSGRAYSIM_CLOUD_TEMPORAL=0` 回退到直接体积云路径用于诊断，该回退也绕过独立的天空雾合成；不能将它当成只关闭一个混合系数的消融实验。

当前仍沿用代表性云可见深度与主场景深度测试，并非所有透明介质与实体的逐像素精确联合光线追踪；正式多装备主控的晴空陆地限制未在本轮扩展。

## 实拍验收

地球测试程序使用台北新数据对应的 `default.map.json`，固定 2026-09-26 04:00 UTC，约 130 个单云对象、8 m/s 风。原始截图均为实际 Vulkan 回读，没有生成或替换效果图。背景主区域 60×60 km，显示延续区 180 km；背景延续不代表全区域都在运行精细物理仿真。

地图包含台北 GLO-30 DSM / Sentinel-2B 2024-02-14 覆盖和全球粗源回退，因此保留原地图的 `provenance_assumed=true` 标记。报告实际源间距约 30.92 m / 10 m、`source_coarse=false`，本轮未修改地图、原始数据或其来源标记。地形显示网格细分不增加真实源细节。

640×360 原始窗口，320×180 云积分、640×360 重建。每机位预热后记录 15 帧，截图回读放在计时之外。下表是整帧渲染提交、天气显示更新与 GPU 完成等待，不是纯 GPU 时间，也不是完整仿真或毁伤耗时：

| 同机位 | 原渲染中位数 | 新渲染中位数 |
|---|---:|---:|
| 云海远景 | 15.01 ms | 14.34 ms |
| 云顶 | 31.21 ms | 19.94 ms |
| 云侧 | 19.94 ms | 15.29 ms |

带风飞行复用原 `route.json`：52 帧相机、时间与相机处密度逐帧相等，密度最大绝对误差 **0**；其中 16 帧位于薄云内。

阴天另用同一 36 个云对象、6 m/s 风完成云下、云底、云顶和地面四机位前后实拍；25 个竖直采样柱的平均透射率保持 0.0008696008，显示改动未改变其物理密度。正式场景设计器也实际打开台北含云专题并保存场景包，暂停时云时钟和天空时钟均为 0 秒、场景 tick 为 0；这项验证不代表已经解除正式多装备测量的晴空陆地限制。

验证覆盖：

- `cloud_temporal_reprojection_gpu`：运行生产 compute SPIR-V，验证静态复用、实际投影像素取样、云深度/透明度失配、移出视锥、清空像素和有限输出。
- 地球程序验证静态历史可用、时间跳变/倒带/切机位拒绝旧历史、恢复后的重新积累。
- `earth_cloud_ocean_consistency`：既有 CPU/GPU 云密度、风、水场与物理云契约。
- `voxel_ocean_gpu_parity`：既有水面/水线/海雾消光积分一致性。
- 统一地球场景和场景包回归通过；本轮没有修改碰撞、断裂或浮力精度。

## 海洋后续优先级

本轮只让远海与云使用同一附加雾，并未升级舰船浮力或水下传感器。现有海洋保留连续波谱、近水面扰动、浮力、尾流、飞沫、Fresnel、日月高光和水体衰减。

1. **天空与云倒影**：当前 `voxel_ocean.frag::sky` 主要是解析天空色和日月亮点。优先增加天空/云辐射缓存或反射探针，配合可用的场景深度反射表现舰体；按粗糙度滤波，并使用受限更新频率和回退路径。避免在每个海面像素重复执行完整云积分。
2. **持久泡沫与尾流**：在现有二维波面上增加随水流平流、扩散和衰减的覆盖场，由浪峰、船边与入水事件驱动，保留可重放状态。这样泡沫能留下、拉开和消散；不必改成三维体素水体。
3. **近岸浪与水色**：需要可靠水深来做变浅、折射、陡化、破浪与浑浊度变化。当前台北 DSM 的水面值不是海床，不能凭它宣称恢复了真实水深；缺数据时仅能提供明确标为推定的演示。
4. **性能与一致性**：GPU 负责波场、法线、泡沫和反射缓存；浮力保留现有水线积分精度，优先批处理、复用空间查询和减少重复计算。水面、浮力与测量继续使用同一波谱、时间和水位基准。水下多波段散射/折射仍需独立实现与标定。
