# 军舰稳性、浮力性能与连续海面

海洋继续采用连续谱波面及光学材质；舰船、地形的体素占用、破坏、刚体和碰撞链路保持原方案。参考用户提供图片中的深青色水体、细密短浪和柔和反光调整显示，不据此宣称复现 GTA6 的渲染技术或达到同等整体画质。

## 原因与质量分布

原 CG-57 预设把舰体和上层建筑的全部占用体积按同一密度处理。名义水线附近，均匀模型重心高度约为 6.31 m，静态初稳性高度估计为 −1.81 m；横向偏心还会进一步激发倾斜。因此单纯增加阻尼、锁定横滚或减少波浪不能正确解决问题。

增加可选 `physics.ballast`，描述一个附着于占用体素的等效点质量：

```json
{"ballast":{"mass_kg":2212568.766790286,"position_m":[-0.1953931881402392,-4.0,-1.6447167109181533]}}
```

这是一组**假定质量分布**：将原名义总质量的 35% 分配到船底等效点，均匀材料密度由 167.303 调为 108.747 kg/m³，总质量仍约 632.16 万 kg。水平位置按几何浮心平衡，重心高度约为 2.70 m，数值倾斜试验估计 GM 约为 +1.79 m。参数不是实际 CG-57 的重心、稳心、压载量或经认证的排水量；没有建立舱室、燃油消耗或进水模型。

引擎把材料与点质量的惯量张量通过平行轴定理合并，再重新计算主惯量轴。既有 Bullet 碰撞子形状仅相对新质量坐标系重新定位，模型几何、体素尺寸、接触面和边距不变。重心处施加冲量不产生伪转矩。断裂时点质量只跟随包含其附着体素的碎块；该体素被删除时清除该质量。检查点保存与恢复该字段。没有该字段的旧场景保留原质量属性，不会被静默修改。

默认更新的场景为 `taipei-coast-ocean.vscene.json`、`taipei-ocean.vscene.json` 和 `taipei-integrated.vscene.json`；独立参考小艇保持原定义。

## 保持精度的性能优化

- 不变：20 ms 默认固定步长、按实际速度决定碰撞子步的规则、2.5 mm 水线曲率积分容差、原占用体积和拖曳面求积。
- 压力体积把竖直连续的占用体素合并成列；体积和孔洞保持精确，水线仍按原 2.5 mm 误差界自适应细分。拖曳继续使用原 2 m 分块和原有面顺序，碰撞形状保持原样。
- 空间相位与时间相位分离。每个固定水动力线程维护有界的空间谱相位缓存，海况改变使其失效。每次力求值仍使用当前时间相位，波包扰动仍按原公式计算；没有复用旧姿态或旧浮力。
- 水深指数项按小区间缓存，五阶局部展开最大归一化偏移 0.05，截断误差低于双精度到 Bullet 单精度的有效精度；另用精确指数路径验证流速和梯度差。
- 刚体点变换直接使用旋转列和位移，省去通用齐次变换；完全位于计算海底上方的盒与拖曳面省去必为零的海底裁剪。
- 倒影失效条件修正：无雾时不因雾光微小色变刷新缓存；月相与有效雾光使用小阈值。纹理仍随实际云、日月方向和刷新周期更新。

`voxel_scene hydro-profile SCENE` 对相同姿态和水场分别测缓存启用/禁用的压力与总水动力，输出质量、GM、力和力矩差。它不含渲染，不能替代完整仿真周期。

## 水面显示

规则短波反光改为二维风驱、带限的解析 simplex 梯度，避免矩形噪声单元轮廓。云倒影在方向空间过滤，反射方向落到地平线以下时不再钳到同一条明亮天空带；云遮挡同时作用于日月盘反射和高光。保留已有海雾、持久泡沫、尾流及入水飞沫。

三个默认军舰预设使用假定的青绿色近岸水体吸收/散射系数，并调整深水背景与界面的亮度平衡。它们是明确的材质参数，不是从截图或 DSM 推导出来的实测台北水质。细波法线属于光学细节，不增加物理波谱、碰撞或破坏精度。没有水深数据，不能据此声称实现了真实浅滩、港口水下地形或近岸破浪；也未凭空生成参考图中的建筑和码头。

## 原生验收

使用台北 GLO-30 DSM 与 2024-02-14 Sentinel-2B 影像，960×540 Vulkan 窗口，同机位、同 UTC 起点 2026-09-10 04:00。100 个匹配样本各推进 100 ms（5 个默认固定步），分别记录渲染、浮力、全部推进和完整周期；截图、数据导入、预热及检查点 IO 不计入稳定耗时。

之后独立继续到 60 秒，检查倾角及物理步无丢失，并执行 90 帧、目标 30 Hz 的真实节奏验证。该工况包含起航、重心冲量和后续减速漂移，不是恒定高速推进验收。额外高视角画面用于评估海面外观，不冒充有旧版匹配机位的性能对照。

```sh
VSGRAYSIM_TAIPEI_DATA_ROOT=/home/mte/EarthData/Taipei80km \
  build/voxel_scene hydro-profile config/earth/taipei-coast-ocean.vscene.json
VSGRAYSIM_OCEAN_WEATHER_PASS=1 VSGRAYSIM_OCEAN_LONG_STABILITY=1 \
  VSGRAYSIM_SOAK_SECONDS=180 build/gui/sim_earth_gui_tests \
  --scene-ocean-capture build/ocean-stability/after
python3 tools/compare_ocean_stability.py
```

实拍与完整数值在 `build/ocean-stability`。旧二进制在修改生产代码前保存为 `earth-before`，旧场景参数可从 `before/checkpoint.json` 核对；新旧轨迹应因质量分布修正而不同，不能要求轨迹相同来判定此物理修复。比较脚本核对占用几何、体素精度、总质量、源数据和采样时间相等。

最终 RTX 4060 Laptop、960×540 的原生结果如下。仿真行均表示一次推进 100 ms，包含 5 个默认固定步；渲染为成功更新/提交及 GPU 完成等待，截图与 IO 排除。

| 范围 | 旧版中位数 | 本轮中位数 | 本轮 P95 |
|---|---:|---:|---:|
| 冻结场景渲染（30 帧） | 11.91 ms | 14.36 ms | 14.72 ms |
| 动态渲染（100 帧） | 74.59 ms | 39.56 ms | 75.77 ms |
| 浮力／推进 100 ms | 217.43 ms | 70.88 ms | 86.86 ms |
| 全部仿真推进／100 ms | 280.50 ms | 119.65 ms | 142.77 ms |
| 完整周期：推进＋渲染 | 356.55 ms | 158.94 ms | 211.42 ms |

完整周期中位数降低约 55%，P95 从 1983.75 ms 降至 211.42 ms。冻结渲染因新增细波和过滤增加约 2.45 ms。动态结果包含稳性修正、正确运动下的碰撞子步变化，以及查询/调度优化，不能当作某个 GPU 算法的独立加速比。

**仍未达到实时。** 目标 30 Hz 的 90 帧节奏测试中，3 秒仿真实际耗时 8.48 秒；该段中位浮力 46.73 ms、全部仿真推进 70.62 ms、渲染 31.95 ms、完整周期 99.56 ms。该段每帧推进 20/40 ms，不能与上表的 100 ms 推进量直接混算。不能根据冻结渲染速度宣称完整仿真已实时，也没有验证 1080p/4K 或多客户端性能。

旧版在 10 秒时倾角约为 99.28°，新版 0–60 秒最大倾角为 1.643°。占用几何、0.359734 m 体素精度及名义总质量均保持不变。显示／碰撞射线最大差为 0.000012647 m。10 秒只记录 33 次倒影更新，避免每帧重复积分。云量切换后纯海面区域的平均 RGB 绝对差为 2.2064 / 255，证明云确实影响水面，而非真实性评分。

同一初始姿态的独立水动力剖析：压力分块 49,751 个，压力列 43,767 个；基准压力中位数 4.13 ms、优化后 3.00 ms，总水动力从 6.53 ms 到 5.19 ms。浮力差为 0 N，力矩差等效作用点偏差约 0.00049 mm，低于保持不变的积分误差界。10 秒检查点的同输入对照中，浮力和力矩读数均相同。九项重建后的 CPU/GPU、断裂、场景包及传感器回归通过，三个正式软件编译通过。
