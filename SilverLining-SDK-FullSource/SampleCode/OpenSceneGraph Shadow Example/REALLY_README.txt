MAKE SURE THE ENVIRONMENT VARIABLE SILVERLINING_PATH IS DEFINED to point to 
the directory containing the SilverLining SDK. Under Windows, this is set 
automatically by the SDK installer, but Linux and Mac users will need to set 
this by hand.

This sample is loosely based on the osgshadow sample application, and has 
been tested with OSG 2.8.3 through OSG 3.4.

The terran in this sample is shaded white, so you can see the shadows more clearly.

For more information, see the SilverLining documentation for OpenSceneGraph 
integration.

As always, if you run into any trouble, don't hesitate to contact 
support@sundog-soft.com for assistance.
